# PRD — CYGEN Equities public marketing website

## Original problem statement
Build the public marketing website for CYGEN Equities (cygenequities.com), an equity-based property partnership platform (React + FastAPI + MongoDB). CYGEN helps a person become full owner of the home they live in through a partnership (LP/GP, trust/SPV, COP, Equity Payment, six-month minimum-payment revision, Payment Halt, Reversed Equity, exit and completion paths, human review of every application). Two start paths: "Buy a home with CYGEN" and "Bring my current home" (no cash-out, no closing-cost funding). Strict banned-word list (EN/ES). Pages: Home, How it works, Refinance, For Limited Partners, For brokers and partners, Workshops (3 sample + registration), FAQ (12+, accordion, FAQ structured data), About, Contact (lead form), Legal (all sections "Draft — counsel to confirm"). Site-wide: EN/ES translation layer with parity, URL locale, hreflang, persisted choice, Spanish review note; theme switch System/Dark/Light (dark default, no flash, WCAG 2.2 AA both themes, verified by computed checks). Exact brand tokens (deep navy/gold/cream). Lead + registration APIs with validation, IP rate limit, honeypot, MongoDB storage, optional HMAC-SHA256-signed webhook forwarding. Password-protected /admin with CSV export. SEO: per-page meta both languages, OG, sitemap.xml, robots.txt, Organization + FAQPage JSON-LD. Automated tests: translation parity, banned-word scan, contrast, form validation. README with env vars, how to add a language, how to change brand tokens.

## User personas
- Prospective Limited Partner exploring either path (buy or bring home)
- Existing homeowner wanting to settle existing financing
- Broker / partner referring clients
- CYGEN staff reviewing leads and workshop registrations (/admin)

## Architecture
- `frontend/src/i18n/` — locale registry + en.json/es.json dictionaries + context (fallback to EN, dev console warning)
- `frontend/src/theme/` — tokens.json (tested source) + ThemeContext (system/dark/light, localStorage, no-flash inline script in public/index.html)
- `frontend/src/components/` — Layout (header/footer/skip link/switchers), Seo (per-page meta, canonical, hreflang, JSON-LD), Shared, FaqAccordion
- `frontend/src/pages/` — Home, HowItWorks, Refinance, LimitedPartners, Brokers, Workshops, Faq, About, Contact, Legal, Admin, NotFound
- `backend/server.py` — /api/leads, /api/workshops, /api/workshops/{id}/registrations, /api/admin/* (X-Admin-Password guard, constant-time compare), IP rate limit (10/10min), honeypot, optional HMAC webhook
- `tests/` — test_translations.py (parity, banned words, FAQ size), test_contrast.py (WCAG computed), test_api.py (validation, honeypot, admin, CSV, rate limit)
